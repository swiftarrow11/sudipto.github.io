I've put off starting a blog for years. The excuses were always the same:
it needs a database, a CMS, a hosting bill, a comment system, an email
newsletter, a server to patch...

So this time I did the opposite. This site has:

- **No database.** Just Markdown files in a Git repository.
- **No server to maintain.** Hugo builds static HTML on GitHub Actions, and
  GitHub Pages serves it for free.
- **No admin panel.** I write posts in my editor and push to Git.
- **No tracking, ads, or JavaScript bloat.** It's fast because it has almost
  nothing in it.

The whole thing fits in one small repo, and I can rebuild it from scratch
anywhere in a couple of minutes. That's the kind of "simple but cool" I'm
going for.

## What you'll find here

- **Tutorials** on software and tooling that I actually use — not rehashed docs.
- **Notes on AI and automation**, which is most of what I build these days.
- **Side projects** and the occasional deep dive into something interesting.

It's for me first — a scratchpad that doubles as a public archive. If you
stumble across something useful, even better.

First real post is up: how I built this site. You're reading the result.
